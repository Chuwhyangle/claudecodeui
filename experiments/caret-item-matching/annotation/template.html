怎么标

  1. 先读右边的 assistant 回复，再读左边这条 user 消息。
  2. 标的是：这条消息在回复里指什么。不是判断匹配器对不对；页面上没有匹配结果。
  3. 如果指向一处具体文字：点回复里的行（可多行）把它填进引文框，或直接粘贴一小段能定位的文字。
  4. 再判断：如果你在输入框里打这条消息时出现一个补全候选，你会用它吗？
  5. 进度自动存在浏览器里。标完点「导出 JSON」，把文件放到 experiments/caret-item-matching/annotation/annotations.json。
